## Problem and prior-proof gap

C014 fixed a real `Shell`/`ManagedArgv` durable-path drop of persisted network intent and sandbox ceiling, and qualified its authenticated rerun/managed owner. C023 reports network enforcement from Bubblewrap's observed setup receipt plus the requested private netns, and no longer mislabels authorized command audits as unrestricted. **Still unqualified:** Tool Program submission spawning child jobs and the complete delegated/rerun ownership chain; **not delivered:** an independently reviewable machine-readable Linux supported-host policy. Those routes were absent from or not end-to-end exercised by the prior native fixture matrix. A prior CI filter matched **zero** tests until C014 fixed it; count/skips cannot be trusted without explicit checking.

## Objective and exclusions

Prove one principal/parent network ceiling survives Tool Program -> JobPayload -> scheduler -> child executor -> `ManagedProcessService` -> helper status/audit, including persisted/restarted jobs, and produce a test-backed host-qualification policy artifact. **Do not** add another executor/network daemon, expand M006 proxy capability, implement cgroup quotas, make a default-offline migration, imply that feature probes prove confinement, or reopen M004/closed C023.

## Acceptance and stop

Pass only with **actual Tool Program delegated child** and the negative host fixture run at exact SHA, stable parent/child ceilings through admission/replay, truthful per-launch reported network, non-vacuous host matrix, machine-readable but **not self-admitting** host policy, and current/default legacy behavior unchanged. If no suitable Linux host/LSM available, record **blocked**, not green-from-skip.

Stop if any nested route silently loses intent, `OfflineRequired` executes with host network, a status receipt is forged from policy/probe alone, a socket/FD crosses isolation, or the test would require operator-unauthorized privileged host changes. Closing this C002 is **not by itself** parent M005 production admission: update the parent gate with evidence and request a separately reviewed host-admission disposition.
