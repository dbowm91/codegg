## 3. Production implementation evidence

`crates/codegg-sandbox` is the helper-facing library. It denies `unsafe_code` through the workspace lint table and does not depend on package `codegg`. `crates/codegg-sandbox-helper` is a bin-only package. It does not inherit workspace lints, does not depend on package `codegg`, and owns the reviewed `unsafe`. The root facade `src/security/sandbox.rs` re-exports the library types and keeps installation-sibling resolution. `SandboxError::Permission` is mapped to `ToolError::Permission` with the same message by an explicit function. A `From` impl is impossible here: `ToolError` is owned by `codegg-core`, `SandboxError` by `codegg-sandbox`, and `codegg-core` does not depend on `codegg-sandbox`.

The installed stem remains `codegg-sandbox-helper`. `SANDBOX_STATUS_VERSION` was not bumped. The frozen status-frame, launch-spec, and process-scope ABI fixtures were not regenerated.
