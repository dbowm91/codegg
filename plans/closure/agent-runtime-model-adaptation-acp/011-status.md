## 3. Production implementation evidence

- Root and descendant execution use the canonical prompt compiler and
  resolved tool surface; no second prompt compiler or role/name authority
  filter is present in production execution.
- Model adapter TOML is strict, generated by Cargo, fingerprinted, and
  included in the `codegg-core` package. Adapter data cannot execute code or
  grant permissions.
- Security and research runtime kinds are host-owned preparation/reporting
  paths layered over ordinary turn, scheduler, tool, and event ownership.
- Recovery uses bounded observable actions and returns a typed stalled result;
  hidden reasoning is not inspected or logged.
- ContextPlan is applied at the provider boundary after history/plugin/tool
  preparation and retains chronological tool protocol state.
- ACP owns only transient request/subscription correlation. Native daemon
  sessions, permissions, turns, projections, cancellation, and durable state
  remain authoritative.

## 6. Invariant review

- Daemon, scheduler, permission, and tool-broker authority is singular.
- Child authority is intersected with parent and hard ceilings; it cannot
  widen tools, paths, shell/Git/network access, or delegation budget.
- Asset, adapter, prompt, tool, and context identities are pinned per turn.
- Descendant work is bounded and cancellation reaches shared child work.
- Specialized runtimes use ordinary ownership and typed reports.
- Recovery is finite and observable-action-only.
- Private reasoning is provider-round-trip state and is omitted from ACP,
  projections, logs, and diagnostics.
- Context reduction is conservative, reversible, and preserves required tool
  protocol state.
- ACP is an adapter, not a second runtime or durable state owner.
- Large, private, and secret content remains bounded, redacted, omitted, or
  handle-backed at the existing boundaries.

## 7. Failure and recovery review

Malformed adapter/configuration, invalid permissions, invalid ACP methods,
oversized frames, duplicate native correlation, cancellation races, daemon
attachment failure, descendant failure, slow projection consumers, and
replay/subscription teardown have explicit bounded paths in the focused
tests and static guards. Restart and durable AgentRun/worktree recovery are
not claimed as complete; they remain the explicitly deferred Phase 9 work.

## 8. Migration and compatibility review

No schema migration is required. Existing agent formats, native protocol,
TUI behavior, provider messages, and projection consumers remain additive-
compatible. Legacy APIs retained by earlier milestones are bounded
compatibility seams: they delegate to or preserve the canonical behavior and
are not authority paths. ACP negotiates only implemented v1 capabilities.
