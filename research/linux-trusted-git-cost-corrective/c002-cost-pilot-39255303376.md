## Interpretation and limits

The contained route is materially faster than snapshot preparation on the measured cold-advised calls and remains below 104 ms maximum in the measured eight-call warm batches. It is slower than native Git, especially for warm `log -1`. The snapshot route's cold-advised p95 is 2.89–3.78 seconds, over the C010 1,000 ms comparator; those end-to-end numbers are not a substitute for C010's earlier private-view preparation gate.

Only contained-live child CPU/RSS was sampled. CPU is reported at centisecond resolution, so most values appear as zero. Native and snapshot child resources were not instrumented. Setup-only time, actual copied bytes/I/O, retained temporary storage, cache eviction, and independent-agent identity contention were not measured. Contention uses simultaneous calls, not separate agent identities. External arbitrary-writer consistency, race/stale-result handling and broad production Git workflow parity remain outside this benchmark. This report is evidence of a promising test-only read path, not production admission or proof of an immutable generation.
